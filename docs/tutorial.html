1它是怎么工作的

接电话这件事分成两半：

你的 iPhoneFaceTime 里创建一条链接，用 iMessage 发给角色
→
Uranus 本体问角色接不接；把你说的话转成文字、让角色回话、合成成语音
⇄
通话节点一个小程序：开浏览器加入 FaceTime，收你的声音和画面、放角色的声音

为什么要单独装一个节点？ FaceTime 只能在浏览器里加入。Uranus 跑在小手机（Cloudflare）、安卓手机上时根本开不了浏览器，所以这一半单独拆出来，装在一台能装 Chrome 的机器上 —— 可以是 Uranus 自己那台，也可以是另一台 VPS、或者你自己的电脑。

节点不存任何 API 密钥：转写、模型、语音合成全在 Uranus 那边做。节点只管「进会议、搬运声音和画面」。

需要准备什么

东西说明
iPhone能用 FaceTime、能用 iMessage 给角色发消息（角色已经绑好了号码）
Uranus 本体v1.22.0 及以上，任何版本（桌面、VPS、安卓、小手机）都行
一台跑节点的机器Linux（Ubuntu / Debian）、Windows、macOS 都行；安卓不行。
内存至少 2G（Chrome 要占 1G 左右）；要装 Node.js 22 以上
浏览器官方版 Chrome 或 Edge。开源的 Chromium 不行 —— FaceTime 的视频要 H.264，Chromium 没有
一个语音合成（TTS）角色说话的声音。Uranus「连接」里配的那家，角色「发语音」那栏填的音色
一个语音转文字（STT）强烈推荐，见下一节
网络FaceTime 网页版在部分地区打不开。节点那台机器要能直接访问 facetime.apple.com（海外 VPS 一般没问题）。

2先在 Uranus 里配好

① 语音转文字（强烈推荐）

连接 → 语音转文字（STT）

  • 中文推荐阿里云 Qwen3-ASR：快（一秒内）、中文准、有免费额度，还会顺带听出你的语气（开心、难过、生气……），别家专门的转写听不出来。
  • 「说的是哪种语言」选中文。不指定的话，短句容易被认成韩语、日语这类外语。
  • 没配转写服务的话，会退回角色「模型」里的「语音识别 API」（Gemini 系模型），能用，但慢好几秒。

② 角色的声音

角色 → 发语音：填好音色 ID。通话里用的就是这个声音。「发语音」那个开关本身不用打开 —— 它管的是发语音条，和接电话是两件事，只是共用一个音色。

③ 角色的模型（按需）

角色 → 模型

这一项通话里拿来干什么不配会怎样
识图 API看你的摄像头画面（「看摄像头」开关）当语音通话，角色看不到你
语音识别 API
只有 Gemini 系模型听得到		听你那边的背景声音（「听背景声音」开关）；没配转写服务时也靠它转写听不出背景

④ 打开接电话

角色 → 接 FaceTime 通话：打开「启用接通话」。下面会出现「通话节点」那一块 —— 先把启用通话节点打开，具体怎么连看第 3 节。

通话用的模型「通话用哪个模型」可以单独选一个快的，并保持「通话时让模型少思考」开着。电话里每多想一秒，你就多等一秒 —— 实测带思考的模型一轮要等 8～25 秒。
通话预设通话有自己的一批预设（和线上、线下分开），默认用「通话默认预设」，在「预设」面板里能改。里面的「怎么打电话」那条教角色别念括号动作、怎么挂电话、没看到摄像头画面时别瞎编 —— 一般不用动。

3选你的部署方式

「通话节点」里第一项是节点在哪。先对照下表找到自己的情况，再跳到对应那一节：

你的 Uranus 跑在节点放哪节点在哪 / 谁连谁看第几节
Linux VPS同一台节点在本机第 4 节
Windows 电脑 / Windows VPS同一台（Edge 系统自带）节点在本机第 4 节
Mac同一台节点在本机第 4 节
VPS，但想把节点放在别处另一台 VPS 或自己的电脑不在本机 · 节点来连 Uranus第 5 节
安卓手机一台 VPS，或自己常开的电脑不在本机 · Uranus 去连节点第 6 节
小手机（Cloudflare）一台 VPSUranus 去连节点（小手机版没有「在本机」）第 6 节
家里的电脑，节点放 VPS一台 VPS不在本机 · Uranus 去连节点第 6 节
「节点来连 Uranus」和「Uranus 去连节点」有什么区别 谁有对方够得着的地址，就让另一方去连它。Uranus 在 VPS 上有公网地址 → 节点来连。Uranus 在安卓、家里电脑上躲在路由器后面，节点连不进去 → 反过来，节点在 VPS 上开一个端口，让 Uranus 连过去。两种用起来完全一样。

先下载节点（每种方式都要）

git clone https://github.com/nikonotnicotine/Uranus_FaceTime.git
cd Uranus_FaceTime

没装 git 的话，到 GitHub 页面点 Code → Download ZIP，解压就行。节点没有任何依赖，不用 npm install。

Linux 上要先装的

# 官方版 Chrome（不能用 Chromium）
wget -qO /tmp/chrome.deb https://dl.google.com/linux/direct/google-chrome-stable_current_amd64.deb
sudo apt install -y /tmp/chrome.deb
# 虚拟显示器：服务器没有屏幕，浏览器要一块看不见的
sudo apt install -y xvfb
# 看一眼 Node 版本，要 22 以上
node -v

Windows / Mac 只要装好 Node.js 22 以上（nodejs.org 下载安装包）；浏览器用自带的 Edge 或装一个 Chrome。

4节点在本机

节点和 Uranus 装在同一台机器上。最省事：不用配对码、不用密钥。

Uranus 这边

角色 → 接 FaceTime 通话 → 通话节点：打开「启用通话节点」，「节点在哪」选节点在本机。没有别的要填。

Linux：装成后台服务

cd Uranus_FaceTime
sudo bash install-service.sh

装好之后开机自启、崩了自己重启，之后再也不用碰命令行。常用命令：

journalctl -u uranus-facetime -f          # 看日志
sudo systemctl restart uranus-facetime    # 重启
sudo systemctl stop uranus-facetime       # 停掉

Windows / Mac：直接跑

在 Uranus_FaceTime 文件夹里打开终端（Windows：在文件夹地址栏输入 cmd 回车），运行：

node src/index.mjs

看到「盯着 http://127.0.0.1:8787，等它派活（本机模式，没用配对码）」就好了。这个窗口别关，关了节点就停了。

确认连上了

控制台 → 通话：显示 ● 通话节点在线 就可以打电话了（第 7 节）。

用 frp、ssh 隧道把别处的节点转进来的别选「在本机」。那种端口转发看起来和本机一模一样，会绕过密钥。选「节点不在本机」。

5节点不在本机：节点来连 Uranus

Uranus 在一台有公网地址的 VPS 上，节点放在另一台机器上（另一台 VPS、或者自己的电脑）。用一串配对码把两边接上。

  1. Uranus 这边：角色 → 接 FaceTime 通话 → 通话节点，「节点在哪」选节点不在本机，「谁连谁」选节点来连 Uranus（用配对码）。
  2. 点「配对密钥」旁边的随机生成，然后点下面那一长串配对码旁边的「复制」。
    注意：要复制的是下面那一长串配对码（eyJ1Ijoi… 开头），不是上面那串短的密钥。
  3. 节点那台机器上配对。Linux： 
    cd Uranus_FaceTime
sudo bash pair.sh
    Windows / Mac： 
    node src/index.mjs --pair
    提示「把配对码粘进来」时粘进去、回车。
  4. 启动节点。Linux 跑 sudo bash install-service.sh 装成服务；Windows / Mac 跑 node src/index.mjs，窗口别关。
  5. 控制台 → 通话 显示「通话节点在线」就好了。
配对码里的地址配对码里打包的是你现在打开控制台用的那个地址。用 localhost 打开控制台、节点却在另一台机器，就连不上 —— 那就用节点够得着的地址（公网 IP 或域名）重新打开控制台，再复制一次配对码。

6节点不在本机：Uranus 去连节点

给安卓、小手机、家里电脑上的 Uranus 用：节点放在一台 VPS 上开一个端口，Uranus 主动连过去，断了会自己重连。

  1. 节点那台 VPS上，先跑一次： 
    cd Uranus_FaceTime
node src/index.mjs --listen 8788
    它会打出配对密钥（也存进了 config.json）。记下来，然后按 Ctrl + C 停掉。
  2. 装成服务：sudo bash install-service.sh。「--listen 8788」已经记在 config.json 里，服务起来就是这个模式。
  3. 放行端口：VPS 控制台的安全组 / 防火墙里放行 TCP 8788；系统里开了 ufw 的话再跑 sudo ufw allow 8788/tcp。
  4. Uranus 这边：角色 → 接 FaceTime 通话 → 通话节点，「节点在哪」选节点不在本机，「谁连谁」选Uranus 去连节点（填节点地址）（小手机版直接就是这一项），填：
    节点地址http://节点那台机器的地址:8788
    配对密钥第 1 步打出来的那串
    保存。
  5. 控制台 → 通话 显示「隧道通了」「通话节点在线」就好了。没通的话那一行会写卡在哪。
小手机必须填域名，不能填 IP Cloudflare 不让 Worker 直接连 IP。弄一个域名指向节点那台 VPS（比如 ft.你的域名.com），节点地址填 http://ft.你的域名.com:8788。
如果域名也托管在 Cloudflare：那条记录要选「仅 DNS」（灰色云），别开代理（橙色云），不然 8788 这种端口过不去。
安卓、电脑上的 Uranus 填 IP 没问题。
安全这个端口对公网开着，所以这条路一定要密钥（第一次 --listen 自动生成），而且隧道只放行通话那几个接口，碰不到 Uranus 的其他东西。

7打一通电话

  1. iPhone 打开 FaceTime → 点「创建链接」 → 用信息（iMessage）把链接发给角色的号码。
  2. 角色会先按人设决定接不接 —— 正忙着、在生气、在开车，完全可以不接，它会用 iMessage 回你。愿意接的话会回一句，接着节点开始加入。
  3. 你自己点开那条链接进入通话。十几秒后 iPhone 上会弹出有人请求加入，点「✓ 允许」。
  4. 接通后角色先开口，然后就像平常打电话一样聊。
  5. 挂断：你直接挂，或者角色自己挂（它会先说完再见）。也可以在 控制台 → 通话 里点「挂断」。

通话里还能

  • 插话：角色说着话你开口，它会停下来听（「允许打断」开着时）。
  • 打字：不方便出声的时候，直接在 iMessage 里给角色发消息，它会在电话里用声音回你。
  • 不说话：45 秒没声音，角色会按人设反应一下（「还在吗？」）。

挂完之后

iMessage 里会留一条「通话结束 · 3 分 12 秒 · 8 轮对话」。通话里说过的话和发短信是同一份聊天记录、同一份记忆 —— 挂了之后在 iMessage 里接着聊刚才电话里的事，角色是记得的。控制台 → 通话 里能看到最近的通话记录。

在外面、周围很吵的时候通话中从 iPhone 右上角下拉打开控制中心 → 麦克风模式 → 语音突显。iOS 会把你以外的声音压掉，对车声、路人说话特别有效 —— 比任何软件上的处理都管用。

8通话里的那些开关

都在 角色 → 接 FaceTime 通话，每个角色单独设。

开关做什么前提
听语气
默认开		你笑着说、带哭腔、生气时，角色知道（平常语气不提）。不多花钱、不多等转写用 Qwen3-ASR；或者没配转写、走语音识别 API
听背景声音
默认开		你在街上、车里、饭馆，或者旁边有人说话，角色知道。在后台听，不拖慢回话，所以会晚一句才说到；30 秒最多听一次，和上次差不多就不提角色配了语音识别 API（Gemini 系）
看摄像头
默认开		你开着摄像头时，角色看得到你在做什么、手里拿着什么、在哪儿。你一开口就截一张去识图，和你说话同时进行；画面没变就不重复看。没开摄像头就当语音通话，角色不会瞎编角色配了识图 API
允许打断
默认开		角色说话时你一开口它就停。关掉的话它会把一句说完—
接通后等多久再开口默认 1500 毫秒。接通那一刻语音通道还没热，太快开口会被吞掉头几个字。还吞字就调到 2000～2500—
多久没说话提醒一次默认 45 秒，0 = 不提醒—
通话用哪个模型 / 少思考见第 2 节，选快的—
通话世界书空着 = 跟线上那份一样；嫌回话慢可以只挑几本薄的—
角色收到的是什么这些听到、看到的东西会以 [小明的语气：开心]、[背景声音：街上，有车流声]、[小明的摄像头画面：对方举着一只猫对着镜头] 这样的标记贴在你那句话前面，角色按人设自己决定要不要接这个话茬。

9常见问题

现象怎么办
控制台显示「通话节点不在线」先看节点日志（Linux：journalctl -u uranus-facetime -f；Windows / Mac：看那个窗口）。节点没跑起来就按第 4～6 节重来一遍。
节点日志一直报 404Uranus 那边「启用通话节点」没打开；或者节点在别的机器上、Uranus 选的却是「节点在本机」。
节点日志报 403 / 密钥不对两边密钥不一样。重新复制一次配对码配对（第 5 节），或者把节点 config.json 里的 secret 抄进 Uranus（第 6 节）。
「隧道没通（连不上）」端口没放行（安全组 + ufw 都要）；地址写错（要带 http:// 和端口）；小手机填了 IP 或域名开了橙色云。
发了链接角色没反应角色的「启用接通话」没开；或者角色选择了不接（看 iMessage 里它回了什么）。
iPhone 上一直没有「请求加入」节点那台机器打不开 facetime.apple.com（地区限制），或者没装官方版 Chrome（Chromium 不行）。看节点日志。
识别不准、认成外语换 Qwen3-ASR，语言选中文；声音太小的话日志里能看到电平（低于 -30dBFS 就是太小）。
开头吞掉几个字「接通后等多久再开口」调到 2000～2500。
回话很慢「通话用哪个模型」选一个快的，开着「少思考」；通话世界书少挂几本。
角色说话把括号、$ 符号念出来检查通话预设里「怎么打电话」那条是不是开着、有没有被改坏。可以删掉重来：恢复成「通话默认预设」。
没开摄像头角色却说「看你在笑」通话预设的「怎么打电话」里有「摄像头」那一节，确认还在。改过预设的话把这一句加回去：「如果没有识别到用户的摄像头画面，不要瞎编用户在干什么，直接当作语音通话即可。」
在外面很吵，角色半天不回打开 iPhone 的「语音突显」（第 7 节）。周围噪音太大时节点会以为你一直在说话。
还是不行带上节点日志和 Uranus 日志（控制台 → 日志）来 QQ 群 1125033956 问。
